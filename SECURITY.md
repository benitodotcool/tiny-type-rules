# Security policy

## Supported versions

Only the latest published version of `tiny-type-rules` receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through [GitHub private vulnerability reporting](https://github.com/benitodotcool/tiny-type-rules/security/advisories/new). You will get an answer within a week.

`fixHtml` rewrites HTML, so anything that could turn text into markup (an entity decoded into `<`, a tag or attribute altered) is a vulnerability worth reporting.
